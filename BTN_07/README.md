* **Nhóm thực hiện:** Nhóm 05

* **Mục tiêu:** Hệ thống hóa kiến thức nền tảng về CRUD, cơ chế giao tiếp API và cách tổ chức mã nguồn theo mô hình MVC bằng ngôn ngữ dễ hiểu kèm ví dụ thực tế.

## Danh mục các tệp báo cáo
1. `01_CRUD.md`: Tóm tắt 4 thao tác CRUD và mẫu code PHP PDO chuẩn.
2. `02_API.md`: Giải thích trực quan về API, RESTful API, định dạng JSON và ví dụ viết API bằng PHP.
3. `03_MVC.md`: Phân tích vai trò của Model – View – Controller và ví dụ tách 3 lớp cơ bản.
